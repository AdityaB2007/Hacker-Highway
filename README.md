Hacker Highway is an educational web game that teaches instruction pipelining and hazards, key concepts in CSC 3501. Instructions are represented as cars moving through five pipeline stages: Fetch, Decode, Execute, Memory, and Writeback. Players identify data dependencies and prevent collisions by inserting stalls or using forwarding. This hands-on gameplay helps players understand how hazards affect pipeline performance and why hazard detection and forwarding are essential.
